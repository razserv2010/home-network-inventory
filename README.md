# המכשירים בבית · Home Network Inventory.

ממשק בעברית לניהול **ידני** של רשימת המכשירים ברשת הביתית. המידע נשמר בשרת מקומי שלך, והטלפון והמחשב מציגים את אותה רשימה דרך הדפדפן. אין גילוי מכשירים אוטומטי ואין צורך ב־Home Assistant.

## מה אפשר לעשות?

- לשמור שם, כתובת IP, כתובת MAC, סוג מכשיר, סוג רכיב, קישוריות והערות.
- לקבל הודעה בממשק רק כשמתפרסם **GitHub Release חדש**, למשל "קיימת גרסה חדשה v1.1.0 - למעבר ל־Repo". הקישור פותח את המאגר וההודעה כוללת את פקודת העדכון `bash UPGRADE`. שינוי README או commit רגיל אינם יוצרים הודעה; היישום אינו משנה את עצמו.
- לחפש ולסנן לפי סוג מכשיר או סוג רכיב.
- לראות את המכשירים תמיד לפי כתובת IP מהנמוכה לגבוהה, גם לאחר חיפוש וסינון; מכשירים ללא IP מופיעים בסוף הרשימה.
- לקבל בהתקנה חדשה קידומת IP התחלתית לפי הכתובת המקומית של השרת: אם הוא נמצא למשל ב־`192.168.1.10`, יוצעו כתובות `192.168.1.x`. אפשר לשנות אותה בכל עת ב־**אפשרויות ← הגדרת רשת LAN**, בלי לשנות כתובות שכבר נשמרו. בחלון הוספת מכשיר אפשר לבחור מתוך כתובות בקידומת הזו שאינן רשומות במאגר, או להקליד כתובת מלאה באותו שדה.
- לראות נקודה ירוקה או אדומה ליד כתובת ה־IP, לפי תגובה ל־Ping מהשרת. המצב נבדק בכל 30 שניות כשהדף פתוח.
- ללחוץ על IP כדי לפתוח `http://<IP>/` בלשונית חדשה, אם יש למכשיר ממשק אינטרנט.
- לסמן כמה רשומות ולמחוק אותן יחד, או למחוק את כל הרשומות לאחר אישור.
- להוריד קובץ גיבוי JSON ולשחזר ממנו. השחזור מחליף את הרשימה הקיימת לאחר אישור.
- להשתמש בתצוגת טבלה במחשב וברשימה נפתחת בטלפון.

**דוגמה לרשומה** (פרטים לדוגמה בלבד):

| שם | IP | MAC | סוג מכשיר | סוג רכיב | קישוריות |
| --- | --- | --- | --- | --- | --- |
| שרת המדיה | `192.168.1.20` | `02:00:00:00:00:20` | Raspberry Pi | שרת | LAN |
| מצלמת כניסה | `192.168.1.30` | `02:00:00:00:00:30` | מצלמה | Reolink | Wi-Fi / Home |

## איפה מתקינים, ואיפה משתמשים?

| תפקיד | מכשירים ומערכות |
| --- | --- |
| **שרת להתקנה** | Raspberry Pi עם Raspberry Pi OS (לדוגמה Pi 3/4/5), או מחשב/שרת Linux עם Debian/Ubuntu, `systemd`, `apt`, Python 3.9 ומעלה וכלי `ping` ו־`ss`. היישום הופעל על Raspberry Pi 4 עם Debian 13; סקריפט ההתקנה הכללי דורש בדיקה בכל מערכת נוספת. |
| **מכשיר לשימוש** | כל מחשב, טאבלט או טלפון עם דפדפן ברשת הביתית, כולל Android, Windows, Linux ו־macOS. בטלפון לא צריך להתקין APK. |

הסקריפט המצורף מיועד ל־Linux עם `systemd` ו־`apt`. התקנה ישירה על Home Assistant OS, Windows, macOS או Docker אינה כלולה. כדי לפתוח את הרשימה מחוץ לבית נדרש פתרון גישה מאובטח כגון VPN.

## התקנה חדשה

התחבר לשרת ב־SSH כמשתמש רגיל (לא `root`) והריץ:

<div dir="ltr" align="left">

```bash
sudo apt update
sudo apt install -y git python3-venv iputils-ping iproute2

git clone https://github.com/razserv2010/home-network-inventory.git
cd home-network-inventory
bash install.sh
```

</div>


סקריפט ההתקנה יוצר סביבת Python, מתקין את התלויות, מזהה את שם המשתמש ואת תיקיית הפרויקט, בודק כבר בזמן ההתקנה איזה פורט פנוי בשרת ובוחר פורט בטווח 8765–8799. הוא מגדיר את הממשק על הפורט שנבחר כשירות `home-inventory.service` שיעלה אחרי אתחול. בהתקנה חוזרת הוא מנסה לשמור את הפורט הקיים; אם הוא תפוס, נבחר פורט פנוי אחר. הבדיקה מתבצעת על השרת שבו מתקינים, ולא סורקת מכשירים אחרים ברשת.

בסיום ההתקנה מוצגת כתובת מלאה בפורמט `http://IP:PORT`. לדוגמה, אם השרת בכתובת `192.168.1.20` ונבחר פורט `8765`, יופיע:

<div dir="ltr" align="left">

```text
http://192.168.1.20:8765
```

</div>

פתח את הכתובת שהודפסה בדפדפן בטלפון או במחשב שמחוברים לאותה רשת. אם כתובת ה־IP לא זוהתה אוטומטית, הרץ בשרת:

<div dir="ltr" align="left">

```bash
hostname -I
```

</div>

והשתמש בכתובת ה־IP של הרשת הביתית ובפורט שהסקריפט הדפיס.

### סמל בטלפון והתקנה דרך Edge

לממשק יש סמל ושם „המכשירים בבית”. פתח את הכתובת בטלפון דרך Edge, פתח את תפריט הדפדפן ובחר **הוסף לטלפון** או **הוסף למסך הבית**, לפי האפשרות שמופיעה בגרסת הדפדפן שלך. כך תוכל לפתוח את האתר מהסמל שבטלפון כשהטלפון מחובר לרשת הביתית.

כתובת מהצורה `http://192.168...` מאפשרת גישה מקומית, אבל התקנה מלאה כאפליקציית PWA דורשת **HTTPS** (או `localhost` במכשיר עצמו). לכן Edge עשוי ליצור קיצור דרך במקום להציע „התקן כאפליקציה”. קובץ ה־manifest והסמלים כבר כלולים בפרויקט; כדי להתקין כאפליקציה דרך הדפדפן ממכשיר אחר צריך גם כתובת HTTPS תקינה לשרת.

### שכחת את הפורט?

בשרת שבו התקנת, הרץ את הפקודה הבאה כדי להציג את הפורט שהוגדר לשירות:

<div dir="ltr" align="left">

```bash
systemctl show home-inventory.service -p Environment --value | tr ' ' '\n' | sed -n 's/^PORT=//p'
```

</div>

כדי לראות גם את כתובות ה־IP של השרת, הרץ `hostname -I`. פתח בטלפון או במחשב `http://IP:PORT`, עם כתובת ה־IP של הרשת הביתית והפורט שהפקודה הדפיסה.

## עדכון

<div dir="ltr" align="left">

```bash
cd ~/home-network-inventory
bash UPGRADE
```

</div>

אם שינית את שם תיקיית ההתקנה, היכנס אליה במקום `~/home-network-inventory`. הסקריפט מושך את הקבצים מהמאגר באמצעות `git pull --ff-only`, מעדכן תלויות ומפעיל מחדש את השירות הקיים. הוא אינו מריץ התקנה מחדש ואינו משנה את הגדרת הפורט; הנתונים בתיקיית `data` אינם נמחקים. יש להריץ אותו כמשתמש הרגיל, ללא `sudo`; תתבקש להזין סיסמה רק עבור הפעלת השירות מחדש. אם שינית קובצי פרויקט מקומית או שקיים מיזוג Git נדרש, הסקריפט יעצור ויציג הודעה במקום לדרוס שינויים. אם גרסה עתידית תדרוש שינוי בהגדרות השירות עצמו, הוראות הגרסה יציינו זאת במפורש.

זיהוי עדכונים פועל כאשר הפרויקט הותקן באמצעות `git clone` ממאגר ציבורי ב־GitHub עם remote בשם `origin`, והשרת יכול לגשת ל־GitHub. הבדיקה משתמשת ב־GitHub Release האחרון ומתבצעת לכל היותר פעם ב־15 דקות; דף פתוח בודק אם יש הודעה כל דקה. אפשר ללחוץ גם על **אפשרויות ← בדוק עדכונים עכשיו** (בהפרש של לפחות עשר שניות מבדיקה קודמת). אם טרם פורסם Release, לא תופיע הודעה. לאחר פרסום Release חדש, משתמש שהגרסה המותקנת שלו אינה כוללת את commit הגרסה יקבל הודעה; שינוי README לבדו לא ייצור התראה. אם אין חיבור לאינטרנט, לא תוצג הודעת עדכון. לאחר שהעלית את הקובץ `UPGRADE` למאגר, אפשר לעדכן בעזרתו.

### מעבר מהגרסה הישנה שהותקנה מקובץ ZIP

1. באתר הישן לחץ על **אפשרויות ← הורדת גיבוי** ושמור את קובץ ה־JSON.
2. שכפל את המאגר **לתיקייה חדשה בשם אחר**, למשל `git clone <כתובת-המאגר> ~/home-network-inventory-public`.
3. היכנס לתיקייה החדשה והריץ `bash install.sh`. הסקריפט יעדכן את אותו שירות וישמור את הפורט הקודם אם הוא פנוי; בדוק את הפורט שהודפס בסיום.
4. פתח את האתר ובחר **אפשרויות ← שחזור מגיבוי**. ודא שהרשומות מופיעות לפני שמסירים את ההתקנה הישנה.

## גיבוי, אבטחה וסטטוס

מסד הנתונים נמצא ב־`data/devices.sqlite3`; תיקיית `data/` מוחרגת מ־Git. הורד גיבוי JSON אחרי שינויים חשובים ושמור אותו במקום נוסף. שחזור JSON מחליף את כל הרשומות, לכן הורד קודם גיבוי עדכני אם יש נתונים שתרצה לשמור.

השרת מאזין לרשת המקומית **ללא התחברות וסיסמה**. כל מי שיכול לפתוח את הכתובת ברשת יכול לערוך ולמחוק רשומות. **אל תפתח את הפורט לאינטרנט.** הכתובות ונתוני המכשירים שלך אינם מועלים ל־GitHub דרך היישום.

הצעות ה־IP מציגות כתובות **שאינן רשומות ברשימת המכשירים** בלבד; הן אינן סריקה של הרשת ואינן מבטיחות שהכתובת פנויה בפועל בנתב. בדוק את הקצאות ה־DHCP או את הנתב לפני הגדרת כתובת קבועה במכשיר. קובץ הגיבוי כולל גם את קידומת ה־LAN; גיבויים ישנים בלי הגדרה זו עדיין נתמכים.

הכיתוב „מחוברים לרשת” / „לא מחוברים לרשת” מחושב לפי Ping, ולא לפי רשימת החיבורים בנתב. מכשיר פעיל שחוסם Ping עשוי להופיע כלא מחובר; למכשיר ללא IP אין חיווי ליד הכתובת.

לבדיקת השירות במקרה של תקלה:

<div dir="ltr" align="left">

```bash
sudo systemctl status home-inventory.service --no-pager
sudo journalctl -u home-inventory.service -n 50 --no-pager
sudo systemd-analyze verify /etc/systemd/system/home-inventory.service
```

</div>
